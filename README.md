# ふくちゃんトーク

家族の秘書フクロウ「ふく」とチャットできるWebアプリ。家計・保険・契約・記念日などの家族情報をAIに質問できる。

🌐 **公開URL**: https://fukurose-jun02.github.io/fukuchan-app/

---

## 概要

「ふくちゃんトーク」は、家族専用のAIアシスタントアプリ。LINEのようなチャットUIで、フクロウキャラクター「ふく」に話しかけると、家族に関する情報を答えてくれる。

### 主な用途

| カテゴリ | 例 |
|---|---|
| 家計 | 「今月の家計を教えて」 |
| 保険 | 「保険の情報を教えて」 |
| 契約 | 「インターネットの契約を教えて」 |
| 記念日 | 「近い誕生日はある？」 |

## システム構成

```
┌─────────────────────────────────────────┐
│           ユーザーのブラウザ              │
│                                         │
│  ┌──────────────────────────────────┐   │
│  │  フロントエンド (index.html)      │   │
│  │  ・PIN認証画面                    │   │
│  │  ・チャットUI                     │   │
│  │  ・会話履歴管理（メモリ内）        │   │
│  └────────────────┬─────────────────┘   │
└───────────────────┼─────────────────────┘
                    │ HTTPS POST /chat
                    ▼
┌─────────────────────────────────────────┐
│  バックエンド (Google Cloud Run)         │
│  fukuchan-backend                       │
│  asia-northeast1 (東京リージョン)        │
│                                         │
│  ・会話履歴を受け取りAIに渡す            │
│  ・家族情報データを保持                  │
│  ・Gemini API を呼び出し                │
└─────────────────────────────────────────┘
```

### フロントエンド

- **ホスティング**: GitHub Pages
- **技術**: 純粋なHTML/CSS/JavaScript（フレームワーク不使用）
- **ファイル構成**:
  ```
  fukuchan-app/
  ├── index.html          # アプリ本体（全コードが1ファイル）
  ├── images/
  │   └── fuku-icon.png   # ふくちゃんのアイコン画像
  ├── .nojekyll           # Jekyll処理を無効化
  └── .github/
      └── workflows/
          └── pages.yml   # GitHub Pagesデプロイワークフロー
  ```

### バックエンド

- **ホスティング**: Google Cloud Run（東京リージョン）
- **エンドポイント**: `POST /chat`
- **リクエスト形式**:
  ```json
  {
    "message": "ユーザーのメッセージ",
    "history": [
      { "role": "user", "content": "..." },
      { "role": "model", "content": "..." }
    ]
  }
  ```
- **レスポンス形式**:
  ```json
  {
    "reply": "ふくちゃんの返答"
  }
  ```

## フロントエンド設計

### PIN認証

アプリ起動時にPIN認証画面が表示される。

- 4桁のPINを入力するとチャット画面に進める
- 3回連続で間違えると30秒ロック
- **注意**: 認証はブラウザ側のJavaScriptで完結しているため、セキュリティ上は「簡易的なアクセス制限」として機能する（DevToolsで回避可能）

### チャット画面

- **デザイン**: スマートフォン向けのチャットUIをベースに、最大幅480pxで中央配置
- **会話履歴**: JavaScriptのメモリ内に保持（最大40ターン）。ページをリロードすると消える
- **送信方法**: 送信ボタン、またはEnterキー（Shift+Enterで改行）
- **クイック返信**: よく使う質問をボタン一発で送信できる

### レスポンシブ対応

| 画面幅 | 表示 |
|---|---|
| 480px以下 | 全画面チャット |
| 481px以上 | 中央に浮かんだカード形式（角丸、影付き） |

## セキュリティ上の注意点

| 項目 | 内容 |
|---|---|
| PIN認証 | クライアント側のみの制御。コードを見ればPINが分かる |
| バックエンドURL | ソースコードに含まれるため公開状態 |
| 会話内容 | バックエンドに送信される。バックエンド側のログ設定に依存 |
| リポジトリ | publicのため、コード・画像・履歴が全て公開 |

本アプリは家族内の利便性を目的としたツールであり、センシティブな情報の管理には適していない。
